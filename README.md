# iLite

![iLite logo](https://ilite.africa/pix/logo_ilite.png)

This is a public repository maintained by iLite for the express purpose of sharing code and helping to further education in the age of AI.

iLite is a Moodle and eLearning services company based in Cape Town and Mauritius. The team focuses on Moodle hosting, platform support, course development, content conversion, and AI-enabled learning tools that help organisations build better learning experiences across Africa.

The iLite website also highlights its AI direction through products such as [Sherpa](https://ilite.africa/sherpa.html) and [iBot](https://ibot.ilite.africa), a Moodle AI assistant designed to help users find and work with course content more intelligently.

Learn more at [ilite.africa](https://ilite.africa).
